## 遷移（7.2）

```
S-01 相手検索 →「取次メモを作成」→ S-04 作成 →（保存）→ S-02 一覧
S-02 一覧 →「取次メモを作成」→ S-04 作成 →（保存）→ S-02 一覧
S-02 一覧 → S-03 詳細 →「編集」→ S-04 編集 →（保存）→ S-03 詳細
S-03 詳細 →「削除」→（確認ダイアログ）→ S-02 一覧
```

- モックの URL：`/memos?recipient=&status=&from=&to=&q=&page=`
  - recipient：空＝すべて、`me`＝自分宛て、数字＝宛先の ID
  - status：空＝すべて、`open`＝未対処、`done`＝対処済み
  - from・to：日本時間の日付（`2026-11-02`）
- 行を押すと S-03 `/memos/:id` を開く（キーボードでは受電日時のリンク）

## 機能（F-03）

- 利用者全員。他人宛ての取次メモも見られる
- 操作の流れ：取次メモ一覧を開く → 絞り込み条件・キーワードを指定して検索する → 行を押して詳細を開く
- 入力
  - 絞り込み：宛先（「自分宛て」を含む）、状態（未対処／対処済み／すべて）、受電日時の期間
  - キーワード：検索欄は1つ
- 処理ルール
  - 開いたときの初期表示は、全員宛て・全状態の取次メモ
  - キーワードは、会社名・氏名・電話番号・伝言・メモのいずれかに部分一致するものを表示する
  - 並び順は受電日時の新しい順
  - 1ページ50件。超えた分はページを分ける
  - 削除された取次メモは表示しない
  - 宛先本人かどうか（「自分宛て」）は、メールアドレスで照合する（F-09）
- 出力：一覧（受電日時、宛先、会社名、氏名、用件、状態、作成者）、「取次メモを作成」ボタン
- F-02：作成を保存すると取次メモ一覧に戻り、「取次メモを登録しました」と表示する。一覧の先頭に作成した取次メモが表示される
- F-04：削除すると一覧画面に戻り、「取次メモを削除しました」と表示する（S-03 から）
- F-09：削除した宛先の取次メモは、データとして残す

## モックで決まったこと（docs/questions.md）

- 検索は入力どおりに比べる（ひらがなとカタカナ、全角と半角を同じものとして扱わない。CLAUDE.md）
- 日時は日本時間で「2026/11/05 14:30」形式（7.1）。期間の絞り込みも日本時間の日付で行う
