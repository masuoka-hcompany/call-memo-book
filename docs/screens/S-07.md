
## 機能（F-06 のうち S-07 に関わるもの）

- 操作の流れ：会社一覧で「新規登録」、または会社の詳細画面で「編集」を押す → 入力して「保存」を押す → 会社の詳細画面に移る
- 入力
  - 会社名：任意。255文字以内
  - 会社名のよみがな：必須。255文字以内。ひらがなのみ（全角スペースは可）
  - メモ：任意。1,000文字以内
- 同じ会社名の会社を登録できる（別の会社として扱う）
- 登録・編集のたびに、更新者・更新日時を記録する
- 保存後：「会社を登録しました」または「会社を更新しました」（S-06 に表示する）
- エラー：入力欄の下に表示し、入力画面にとどまる。保存しない
  - 必須項目が空：「{項目名}は必須です」
  - よみがなにひらがな以外が含まれる：「会社名のよみがなはひらがなで入力してください」
  - 文字数の上限を超える：「{項目名}は{上限}文字以内で入力してください」

## モックで決まったこと（docs/questions.md）

- 空白だけの入力は「空」（Q-M07）
- よみがなはひらがな（小書き文字・「ゔ」を含む）、長音「ー」、全角・半角スペース（Q-M08）
- 1つの欄に当てはまるエラーはすべて出す（形式 → 文字数の順。Q-M09）
- 会社名・よみがなは前後の空白を削ってから確かめ、保存する。メモは削らない（Q-M11）
- 改行は1文字と数える（仮。Q-M06）
