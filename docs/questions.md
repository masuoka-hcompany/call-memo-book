# モックの未決・疑問点

モックを作る中で出た、`docs/spec.md` に書かれていない点や食い違い。レビュー会で決めてもらう。

- ID は `Q-M01` からの連番（仕様書 11章の `Q-xx` と区別する）
- 画面の【未決】バッジにも同じ ID を出す
- 決まったら「状態」を「解決」にし、決まった内容を「内容」に追記する（`docs/spec.md` の更新は人間が行う）
