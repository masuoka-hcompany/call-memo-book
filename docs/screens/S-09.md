## 機能（F-07 のうち S-09 に関わるもの）

- 操作の流れ：会社の詳細画面で「担当者を追加」、または担当者の「編集」を押す → 入力して「保存」を押す → 会社の詳細画面に戻る
- 入力
  - 担当者名：任意。255文字以内
  - 担当者名のよみがな：必須。255文字以内。ひらがなのみ（全角スペースは可）
  - 電話番号：必須。半角数字のみ（ハイフン不可）。15桁以内
  - メモ：任意。1,000文字以内
- 担当者は必ず1つの会社に属する（会社の詳細画面から登録する）
- 担当者を別の会社に移すことはできない（編集で所属する会社は変えない）
- 同じ電話番号の担当者を複数登録できる
- 登録・編集のたびに、更新者・更新日時を記録する
- 保存後：会社の詳細画面に戻り、「担当者を登録しました」または「担当者を更新しました」と表示する
- エラー：入力欄の下に表示し、入力画面にとどまる。保存しない
  - 必須項目が空：「{項目名}は必須です」
  - よみがなにひらがな以外が含まれる：「担当者名のよみがなはひらがなで入力してください」
  - 電話番号に半角数字以外が含まれる：「電話番号は半角数字のみで入力してください」
  - 電話番号が16桁以上：「電話番号は15桁以内で入力してください」
  - 文字数の上限を超える：「{項目名}は{上限}文字以内で入力してください」

## モックで決まったこと（docs/questions.md）

- 空白だけの入力は「空」（Q-M07）
- よみがなはひらがな（小書き文字・「ゔ」を含む）、長音「ー」、全角・半角スペース（Q-M08）
- 1つの欄に当てはまるエラーはすべて出す（形式 → 文字数の順）。ただし電話番号は、半角数字以外が含まれるときは桁数のエラーを出さない（Q-M09）
- 担当者名・よみがな・電話番号は前後の空白を削ってから確かめ、保存する。メモは削らない（Q-M11）
- 改行は1文字と数える（仮。Q-M06）
