## 遷移（7.2）

```
S-05 会社一覧 →「新規登録」→ S-07 登録 →（保存）→ S-06 会社詳細
S-05 会社一覧 → S-06 会社詳細 →「編集」→ S-07 編集 →（保存）→ S-06 会社詳細
S-06 会社詳細 →「削除」→（確認ダイアログ）→ S-05 会社一覧
```

## 機能（F-06 のうち S-05 に関わるもの）

- 操作の流れ：会社一覧で「新規登録」を押す → S-07
- 会社一覧：会社名、よみがな、担当者数を表示する。よみがな順。検索欄は1つ（会社名・よみがなに部分一致）
- 会社名が空の会社は、会社一覧で名前の代わりによみがなを表示する
- 同じ会社名の会社を登録できる（別の会社として扱う）
- 削除後：会社一覧に戻り、「会社を削除しました」と表示する
- 削除された会社は表示しない（論理削除。CLAUDE.md「論理削除」）

## 関連するユースケース

- UC-05：会社・担当者を登録・編集・削除する

## 状態

| 状態 | 表示 |
|---|---|
| 開いたとき | 削除されていない会社をすべて、よみがな順に表示する（AC-58） |
| 検索したとき | 会社名・よみがなに部分一致する会社だけを表示する（AC-57）。比べ方は入力どおり（ひらがなとカタカナを同じものとして扱わない） |
| 会社を削除したあと（S-06 から） | 「会社を削除しました」（AC-24） |
| 0件 | 仕様書に定めがない（`docs/questions.md` Q-M13） |
| 検索欄を空のまま検索 | 仕様書に定めがない（`docs/questions.md` Q-M12） |
