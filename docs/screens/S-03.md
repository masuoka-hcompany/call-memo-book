# S-03 取次メモ詳細

`docs/spec.md` から S-03 に関わる部分を抜き出したもの。食い違ったら `docs/spec.md` が正。

## 画面（7.1）

| 項目 | 内容 |
|---|---|
| 画面名 | 取次メモ詳細 |
| 目的 | 取次メモの内容を確認し、編集・削除・対処済みの操作をする |
| 主な要素 | F-02 の入力項目すべて、作成者、作成日時、状態、「編集」「削除」ボタン、「対処済みにする」／「未対処に戻す」ボタン |
| 遷移先 | S-02, S-04 |
| 関連機能 | F-03, F-04, F-05 |
| メニュー | 取次メモ一覧 |

## 遷移（7.2）

```
S-02 一覧 → S-03 詳細 →「編集」→ S-04 編集 →（保存）→ S-03 詳細
S-03 詳細 →「削除」→（確認ダイアログ）→ S-02 一覧
```

- モックの URL：`/memos/:id`。対処済みにする `POST /memos/:id/done`、未対処に戻す `POST /memos/:id/reopen`、削除 `POST /memos/:id/delete`
- 削除された・存在しない取次メモは 404

## 機能

### F-03（詳細画面の表示）
- F-02 の入力項目すべて（宛先、受電日時、会社名、氏名、電話番号、用件、伝言、メモ）、作成者、作成日時、状態
- 更新者・更新日時、対処済みにした人・日時は表示しない（記録のみ）
- 会社名・氏名・電話番号は作成時の値（会社・担当者を後で編集しても変わらない。F-02）

### F-04（編集・削除）
- 「編集」「削除」ボタンは全員に表示する。対処済みの取次メモも編集・削除できる
- 作成者以外が編集しても、作成者の欄は変わらない
- 編集を保存：詳細画面に戻り、「取次メモを更新しました」
- 削除の確認ダイアログ：「この取次メモを削除しますか？」→「削除する」
- 削除後：一覧画面に戻り、「取次メモを削除しました」。削除は論理削除。更新者・更新日時を記録する

### F-05（対処済み・未対処の切り替え）
- 全員（宛先本人以外も可）
- 未対処のときは「対処済みにする」、対処済みのときは「未対処に戻す」を表示する（全員に表示する）
- 確認ダイアログは出さない。一覧の行からは操作できない（詳細画面からのみ）
- 対処済みにした人と日時を記録する。未対処に戻したら消す（画面には表示しない）
- 詳細画面にとどまり、状態の表示を切り替え、「対処済みにしました」または「未対処に戻しました」と表示する
- 開いただけでは対処済みにならない
