## 遷移（7.2）

```
S-01 相手検索 →「取次メモを作成」→ S-04 作成 →（保存）→ S-02 一覧
```

- モックの URL：`/`。検索は `/?q=原田`、相手を選ぶと `/?q=原田&contact=1`（担当者の行）・`/?q=ミイダス&company=1`（会社だけの行）
- 「取次メモを作成」は `/memos/new`。相手を選んでいれば `?contact=`・`?company=` を付けて S-04 に渡す（S-04 で会社名・氏名・電話番号を自動で入れる）

## 機能（F-01）

- 操作の流れ：検索欄に入力して検索する → 検索結果が表示される → 相手を選ぶ → 宛先ごとの取次可否が表示される → 必要なら「取次メモを作成」を押して F-02 に進む
- 入力：検索キーワード（検索欄は1つ）
- 会社名、会社名のよみがな、担当者名、担当者名のよみがな、電話番号のいずれかに部分一致する相手を表示する
- 会社名（よみがな）に一致した場合は、その会社の担当者全員を表示する
- 担当者が登録されていない会社は、会社名だけの行として表示する
- 削除された会社・担当者は表示しない
- 検索欄が空のまま検索した場合は、検索しない
- 検索結果の並び順は指定なし（モックでは会社のよみがな順、同じ会社の担当者は登録順）
- 会社名・担当者名が空の会社・担当者は、名前の代わりによみがなを表示する
- 検索結果：1行に会社名、担当者名、電話番号（担当者ごとに1行）
- 相手を選んだあと：宛先ごとに「会社の取次可否」と「担当者の取次可否」を並べて表示する。採用される値（優先ルール：担当者が「未設定」以外なら担当者、「未設定」なら会社）の強調のしかたは画面モックで決める。会社だけの行を選んだ場合は、会社の取次可否だけを表示する。削除された宛先は表示しない
- 検索結果が0件：「該当する相手が見つかりません」と「取次メモを作成」ボタン（押すと F-02 の作成画面がすべて空欄で開く）

## 取次可否の表示（docs/design.md 5章）

- 宛先ごとに1行で「宛先｜判定｜内訳」。判定は採用値を枠か塗りで表示（✕ つながない／● つなぐ／― 未設定）
- 内訳は「担当者：〇〇　／　会社：〇〇」。採用された方を太字と「← 採用」で示す
- 会社だけの行を選んだときは、内訳を「会社：〇〇」だけにする（「← 採用」は付けない）
- 部品は `src/views/verdict.tsx`（`/__styleguide` の見本と同じ）。採用値は `src/domain/setting.ts` の `resolveSetting`
